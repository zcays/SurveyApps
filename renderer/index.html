DOCUMENTATION & METHODS

SurveyApps! Reference Guide

Practical workflows, mathematical conventions, keyboard shortcuts, and privacy guarantees for both scientific tools.

1. Grid Studio (Digital Microscope Gridoverlay Studio)

Designed for aligning microscope photos of microfluidic chips to a precision reference grid so optical distortions can be removed before export.

  • Product Rule — Static Grid, Adjustable Image: The reference grid never moves with the photograph. Instead, you translate, scale, rotate, lens-correct, and warp the underlying micrograph until its physical wells align with the static overlay.
  • Chip Presets & True-to-Scale Geometry: When a chip version is selected, well width and pitch are scaled in micrometres (µm) using a shared factor k (canvas px per µm), preserving exact well : wall : pitch proportions where pitch = well + wall. With Fit canvas to array enabled, the document resizes to the exact N × M well array plus border margin.
  • Lens & Distortion Pipeline: Pass 1 applies inverse translation, rotation, scale, and radial fisheye correction r' = r(1 − k₁r² − k₂r⁴). Pass 2 maps the corrected image onto a 32×32 mesh controlled by a 3×3 biquadratic patch (Distort tool).
  • Computer-Vision Auto-Fit (Key A): Computes 2D FFT power spectra of image gradients |gx| and |gy| to find the fundamental well lattice frequency, performs complex phase demodulation and quality-guided flood-fill unwrapping, locates array boundaries, and solves for tilt, scale, translation, radial k₁, and corner warp. Auto-fit refuses rather than guesses if median residual error exceeds 10% of a period or fewer than 75% of samples match.
  • GPU & Software Renderers: Automatically uses WebGL2/WebGL1 hardware shaders and falls back seamlessly to a matching Canvas 2D software renderer if GPU acceleration is unavailable.

2. Fluorescence Lab (Microscopy Grid Overlay)

Built on Python (Dash, Plotly, Pillow, NumPy) for interactive orthogonal well framing, multi-channel pixel intensity calculation, heatmap visualization, and well cropping.

  • Supported Image Formats & Orientation: Upload high-resolution TIFF, PNG, or JPEG microscopy images. Intrinsic EXIF orientation tags are respected on load, and image rotation is cached in memory for responsive slider feedback.
  • Orthogonal Grid Alignment: Rotate the slide image beneath the orthogonal grid and tune Grid Spacing, Grid X Offset, Grid Y Offset, and line opacity until each well (A1, A2, B1…) frames its target sample region.
  • Channel & Fluorophore Selection: Choose Mean Grayscale, isolated RGB channels, or standard Echo fluorescence channel profiles (DAPI, FITC / GFP, TRITC / Texas Red, Cy5, mCherry, CFP, YFP) and click Compute Fluorescence to populate the interactive Plotly matrix heatmap.
  • Truthful Quantitative Interpretation (8-Bit Channel Intensity): All computed matrix values are 8-bit digital channel intensities (0–255) calculated from the image's pixel arrays. They are not calibrated physical concentrations (e.g., µM or ng/mL). For valid cross-image comparisons, keep microscope exposure, illumination intensity, camera gain, and file bit-depth conversion constant across your experiment.
  • Exports & Reproducibility: Export the well intensity matrix to CSV, crop and download individual labeled wells (e.g., A1, B4), download the composite Grid + Image PNG, or save/reload your grid configuration JSON.

4. Offline Privacy, Security & Session Persistence

  • 100% Offline Execution: SurveyApps! bundles all required front-end assets and the standalone Python scientific runtime locally. No internet connection is required, and no external CDN scripts, web fonts, or telemetry beacons are loaded.
  • Zero External Data Transmission: Unpublished experimental micrographs, microfluidic chip designs, and fluorescence CSV exports remain strictly on your local filesystem.
  • Isolated & Authenticated Local Backend: The Electron main process spawns the frozen Python backend bound exclusively to loopback (127.0.0.1) on an OS-assigned ephemeral port with a per-launch authentication token, and terminates the child process cleanly when you quit the app.
  • Persistent Tool Sessions: Once opened, both Grid Studio and Fluorescence Lab stay mounted in persistent background frames while you switch between Dashboard, tools, and Help—preserving your loaded micrographs, sliders, and computed heatmaps throughout your session.
